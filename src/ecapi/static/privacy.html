Privacy

Last updated 19 November 2026.

The short version

This site and its API don't collect anything about you. There are no accounts, cookies, analytics, trackers, ads, forms, or third-party scripts or fonts. The page you're reading and the query builder only load files from this same site.

Using the site and the API

  • No cookies or local storage. Nothing is saved in your browser.
  • No analytics or tracking. We don't count, profile or identify visitors.
  • The query builder runs in your browser. Your filter choices aren't sent anywhere. The page just requests the matching public JSON file from this site.
  • No API keys or sign-up. Requests are anonymous downloads of static files.

Hosting (GitHub Pages)

This site is hosted on GitHub Pages. Like any web host, GitHub receives standard request information when you load a page or API file, such as your IP address, browser user-agent and the URL requested, and may keep it for security and operational purposes. We can't see or access those logs. GitHub's handling of that data is covered by the GitHub General Privacy Statement.

The data this API publishes

The API lists student clubs, teams and other extracurriculars, collected from the schools' and student societies' own public directories. Each record links back to its original listing.

  • Collected: club-level information only. That's the name, the club's own description, category, faculty, public links (website, Instagram) and recruitment status.
  • Not collected: information about individual people. That means no executive or member names, no personal email addresses or phone numbers, and no photos. Some source pages list executives' names, and we deliberately skip them.
  • How it's collected: an automated job attempts to refresh the data weekly. It obeys each site's robots.txt, including requested delays between requests, and identifies itself honestly.
  • Accuracy: descriptions and links are reproduced as the sources publish them. Some fields are inferred from that text, and each record's provenance shows how. Always confirm details on the original listing.

Not affiliated with any school

This is an independent project. It is not affiliated with, endorsed by, or sponsored by any school, student government, society or club whose information it lists. School, society and club names belong to their respective owners and are used only to identify them. Information comes from their public directories and may be out of date or wrong: always confirm on the original listing.

Corrections and removal

If you run a club listed here, or you see something that's wrong, out of date or shouldn't be public, open an issue on this project's GitHub repository with the activity's id and what should change. Please don't include personal details in a public issue. If a request is about information that shouldn't be public, say so, and we'll remove the record and keep it out of future updates.

Removing something here doesn't remove it from the original directory. For that, contact the club or the organisation that publishes the directory.

Changes

If this policy changes, this page will be updated and the date at the top will change.
