Extracurricular API

Free JSON listing of university clubs, design teams, conferences and more. Collected from each school's own public directories, with an attempted refresh every week (check data_as_of for actual freshness). No key, no sign-up: just fetch a URL.

Endpoints

All paths are relative to this page. {school} is a school id from v1/schools.json (currently queens).

What you wantEndpoint
Which schools are coveredv1/schools.json
A school's faculties, data sources, freshness, and every valid filter valuev1/{school}/info.json
Everything at a schoolv1/{school}/all.json
One activityv1/{school}/item/{id}.json
Activities matching filtersv1/{school}/filter/fac-…/sub-…/type-…/app-…/first-….json
All tags, with countsv1/{school}/tags.json
Activities with one tagv1/{school}/tag/{tag}.json

Filter segments

A filter URL always has all five segments, in this order. Each names what it filters, and -any means "don't filter on this".

#SegmentValues
1fac- facultyfac-any, fac-general (open to every faculty), fac-arts-science, fac-business, fac-engineering, fac-health-sciences, fac-education, fac-law, fac-graduate
2sub- subfacultysub-any, or a programme inside the chosen faculty: sub-computing, sub-commerce, sub-civil-engineering, … (listed per faculty in info.json)
3type-type-any, type-club, type-team, type-design-team, type-discipline-club, type-committee, type-conference, type-competition
4app- applicationsapp-open (accepting now), app-closed, app-unknown, app-any
5first- first-yearsfirst-focused (made for first-years), first-friendly (first-years can join, includes focused), first-no, first-unknown, first-any
